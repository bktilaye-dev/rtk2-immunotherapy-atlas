# RTK II Immunotherapy Atlas

A graded, filterable reference dashboard of immunotherapy approaches worldwide relevant to **IDH-wildtype glioblastoma, RTK II (RTK2) methylation subclass** — organized by mechanism (T-cell activation, NK cell response, stem-cell delivery combinations, IL-15/Anktiva-like superagonists, and CD8⁺ isolation & adoptive transfer), with each entry staged by clinical evidence (Preclinical → Phase 1 → Phase 2 → Phase 3 → Approved).

Open `rtk2-immunotherapy-atlas.html` directly in a browser — it's a single self-contained static page (no build step, no server).

## What's inside

- 27 tracked approaches, each with sponsor, location, recruiting status, evidence grade, and a source link
- Search, mechanism-group filters, minimum evidence-stage filter, and a recruiting-only toggle
- A summary of counts and an overview chart by mechanism group

## Sources

ClinicalTrials.gov, sponsor press releases, and peer-reviewed literature, compiled September 2026.

## Disclaimer

This is a research-organization aid for discussion with a treating neuro-oncologist — **not medical advice**. RTK II is a DNA-methylation subclass identified after surgery, not a treatment indication most trials enroll by; nearly every entry enrolls on IDH-wildtype glioblastoma histology broadly, not RTK II status specifically. Evidence status (phase, recruiting state) reflects public registries as of the compilation date and can change — always re-verify with the source link before acting on it.
